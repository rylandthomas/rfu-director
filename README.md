# RFU Director — Career Governance V1.9

A browser-based long-term Rugby Football Union management career. You are the RFU Director, not the England head coach: your job is to govern the whole English game and survive the consequences of the system you build.

## Run

Open `index.html` directly in a modern browser.

Optional local server on Windows:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Career loop

- Work from the **Director's Desk** rather than a match-manager dashboard.
- Operate under a **four-year RFU Board Mandate**.
- Be judged across four pillars: financial resilience, England performance, the English rugby pipeline, and professional-game stability.
- Receive annual scorecards and a full mandate review.
- Strong performance earns another mandate; middling performance can bring probation; severe failure can end the tenure.
- The **This Period's Business** panel surfaces only issues that genuinely need RFU-level action.
- A **Tenure Ledger** keeps a record of major decisions and board scorecards.

## Development

Development is now one coherent management area with sub-tabs for:

- Overview — national programme budgets
- Regional Network — 10-region long-term development model
- Facilities & Infrastructure — national stadium and performance assets
- England Pathway — academy/U18/U20/senior programme funding and age-grade operating budgets

Regional investment has delivery time, operating support, maintenance, decay and cohort-lagged player-production effects. The network is stored in the main career save and advances with the main season.

## Existing systems retained

- England manager employment/review system
- England players and selection-policy rules
- Live international match simulation
- Premiership and Championship background simulation
- Hidden club finance/contracts/player movement
- Professional Game Partnership decisions
- RFU finances and commercial deals
- Stakeholder relationships and media/events
- Capital projects
- Local browser save and multi-season progression

V1.9 deliberately strengthens the boardroom career loop without turning the RFU Director into the England coach or a Premiership club owner.
